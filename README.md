Android app (4 files bundled inside the APK, works offline).
Generated by ToolDeck APK Maker (https://www.tooldeck.online/apk-maker).

## HOW TO BUILD THE APK

1. Unzip this file.
2. Upload ALL of these files to a new private GitHub repository.
3. In GitHub click **Add file** -> **Create new file**.
4. Name it exactly: **.github/workflows/build.yml**
5. Paste the YAML from the ToolDeck page and click **Commit changes**.
6. Open the **Actions** tab, click "Build signed APK", then "Run workflow".
7. Download the signed APK. Also save the "keystore-keep-private" file: you need it for future updates.

## Changing your app later

Your files live in app/src/main/assets/www/ . Replace the files there, raise versionCode in app/build.gradle.kts and build again.
